Stage 3 · Sourcing

Equivalent is not the same as drop-in

Same chip family. What actually differs:
  1. Size and mounting holes
  2. Pin order and labels
  3. Power input and regulator
  4. Antenna and keep-out zone
  5. Onboard LED and button pins
  6. Board definition in your tools
"Same chip," they said.

Equivalent means it does the same job. Drop-in means it fits the same hole.

Choosing the brain

Microcontroller or single-board computer?

Microcontroller · MCU

Runs one program, forever.

  • Starts in milliseconds
  • Sips power — battery-friendly
  • Precise, real-time input and output
  • No operating system to update
ArduinoESP32Raspberry Pi Pico
Single-board computer · SBC

Runs an operating system.

  • Linux, Python, cameras, screens
  • Room for local AI models
  • Boots in seconds; needs a clean shutdown
  • More power, more heat
Raspberry Pi 5Raspberry Pi Zero 2 W

A microcontroller is a light switch with a brain. A single-board computer is a tiny laptop without a screen.

Stage 5 · CAED

CAD as code: geometry an agent can edit

focus_shell.py · CadQuery
import cadquery as cq

D, H, WALL = 72, 28, 2.42.0  # mm

shell = (
  cq.Workplane("XY")
  .polygon(6, D)        # hex footprint
  .extrude(H)
  .edges(">Z").fillet(4)
  .faces(">Z").shell(-WALL)
)
cq.exporters.export(shell, "focus_shell.step")
A render

Pixels. No dimensions. Can't be measured, edited or printed reliably.

A parametric model

Dimensions, constraints, editable history. Exports STEP, STL, 3MF.

Stage 5 · Inside out

Designed from the inside out

Fit. Feel. Assembly. Repair.

The interior is part of the user experience.

  • Leave room for wires, connectors, screws and air gaps
  • Design for real tolerances, not perfect ones
  • Prefer screws to glue

Glue is a one-way door. Future you would like a screwdriver.

Stage 5 · Design for manufacture

Design for the printer, not just the screen

Walls

Multiples of the nozzle

With a 0.4 mm nozzle, 1.2, 1.6 or 2.0 mm walls print as clean, solid perimeters.

Overhangs

Respect 45°

Up to about 45° prints without support. Chamfer downward edges instead of filleting them.

Clearances

Gaps are a feature

Sliding fits need roughly 0.2–0.3 mm per side. Print a test coupon before you trust a number.

Holes

They print small

Add about 0.1–0.2 mm to small holes, or drill to size afterwards.

Strength

Mind the layers

Parts are weakest between layers. Orient so loads run along them, not across.

Inserts

Heat-set, not glued

Size holes to the insert maker's spec and leave solid wall around each one.

Rules of thumb for FDM with a 0.4 mm nozzle. Your printer and material get the final vote.
